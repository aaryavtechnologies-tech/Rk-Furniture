# R.K. Furniture | Royal Wood Carving Atelier Saharanpur

Official luxury landing page and bespoke furniture catalog for **R.K. Furniture**, manufacturer, order supplier, and specialist in handcrafted royal wood carving furniture in Saharanpur, Uttar Pradesh, India.

## Features
- **Ultra-Luxury Atelier Design System**: Obsidian black & 24K gold theme, glassmorphism 2.0, responsive layouts.
- **Interactive Hero Masterpiece Switcher**: Auto-rotating showcase featuring authentic workshop furniture.
- **Craftsmanship Transformation Showcase**: Dual-view comparison of unpolished raw teak frames and 24K gold-leaf finished palace suites.
- **Interactive Configurator 2.0**: Dynamic live price estimator and instant WhatsApp specification generator.
- **Masterpiece Gallery**: Real-time keyword search and category filtering across authentic handcrafted pieces.
- **Direct Workshop Connectivity**: Direct WhatsApp inquiry and live workshop video call scheduling with proprietor Kaleem.
- **Accessible & Semantic**: Accessible `<dialog>` modals for quick view specs and custom quotes.

## Tech Stack
- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Design Tokens, Micro-animations, Glassmorphism)
- Vanilla JavaScript (Interactive Controllers & Dynamic Estimators)

## Local Development
Run any static HTTP server in the project directory:
```bash
npx serve .
# or
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
